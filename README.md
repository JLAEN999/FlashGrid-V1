# 闪阵 FlashGrid V1

面向 ESP32 的 Windows 多设备烧录与串口调试工具。

## 下载与启动

在 [Releases](https://github.com/JLAEN999/FlashGrid-V1/releases) 下载 `FlashGrid-V1-Windows-x64.zip`，解压后双击 `FlashGrid-V1.exe`。无需安装 Python。首次启动会解压内置运行库，请稍候。

## 功能

- 最多 8 路串口并行烧录，支持多固件地址配置、芯片选择及擦除。
- 工业浅色界面，显示烧录统计、成功率和设备状态。
- 串口原生日志连续显示，各端口分别查看，支持复制、粘贴和保存。
- 串口掉线后自动等待重连；设备有唯一 USB 标识时可跟踪变化后的 COM 号。
- 支持串口参数设置、HEX 收发、关键词检测和动态快捷命令。

## 使用方法

1. 安装设备所需的 USB 串口驱动，并关闭占用同一串口的其他程序。
2. 在“烧录”页面选择端口、芯片、固件和正确的烧录地址，然后点击“开始烧录”。
3. 在“串口调试”页面选择端口和波特率，点击“打开串口”。设备掉线后会自动等待恢复，点击“关闭串口”可停止重连。
4. 快捷命令可新增和删除，修改后会保存到软件同目录的“快捷命令.json”。

## 日志说明

接收区保留设备自己的换行，不添加 RX 或时间戳前缀。USB 重新枚举或驱动尚未开放串口期间的日志无法由软件补回。需要捕获最早开机输出时，建议让 USB 转串口模块保持供电，仅切换目标设备电源。
